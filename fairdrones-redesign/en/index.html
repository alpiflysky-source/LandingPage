The problem is not the terrain, it is the logistics

Where customers are few and there is no road, every delivery costs as much as a big one. Small, frequent deliveries are exactly what goes missing.

Where it happens

  • Mountain huts and alpine farms
  • Small islands
  • High-altitude work sites and facilities
  • Isolated buildings and homes

Strengths

  • Multi-operator

    A network open to authorised operators, not a single fleet.

  • Any make

    Hardware and software independent of the drone.

  • Local data

    Weather measured where you fly, the same for every operator.

  • Shared missions

    Several requests in one flight, with the cost shared fairly.

We start in the mountains, the hardest terrain

The network built across mountain huts becomes the base for every difficult scenario.

  1. Phase 0

    With operators: field tests of hardware and software on their authorised routes.

  2. Phase 1

    Infrastructure across many huts: installed stations and a network of operators.

  3. Phase 2

    More mountain scenarios and increasingly automated operations.

  4. Vision

    Every difficult scenario: the reference infrastructure for drone transport.
